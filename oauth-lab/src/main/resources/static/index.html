FinAccess 사용자 앱

Keycloak에서 Access Token을 받고, FinAccess Spring API를 직접 호출합니다.

1. Access Token 받기

Keycloak에서 일반 사용자 alice로 인증합니다. 비밀번호는 이 페이지에 입력하지 않습니다.

아직 받은 토큰이 없습니다.
토큰은 메모리에만 보관합니다. 새로고침하면 사라집니다. 토큰 지우기는 Keycloak 세션 종료나 서버의 토큰 폐기가 아닙니다.

2. FinAccess USER API 호출

브라우저 → FinAccess Spring · GET /api/user/me

요청 결과가 여기에 표시됩니다.
예상 결과: USER 역할이면 200 · USER 역할이 없으면 403 · 토큰이 없으면 401

FinAccess가 화면과 USER API를 함께 제공합니다. FinAdmin은 별도 화면 없이 curl로 API7을 경유하여 호출하는 구성입니다.
