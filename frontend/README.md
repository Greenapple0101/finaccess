# 과거 프런트 보관 폴더

여기의 금융·ITSM HTML·JavaScript는 현재 OAuth2 최소 실습 화면이 아닙니다. 현재 화면은 [oauth-lab/src/main/resources/static](../oauth-lab/src/main/resources/static)에 있고 FinAccess 로컬 JVM이 18100으로 제공합니다.

API 호출은 API7의 `/oauth-access/api/user/me`를 경유합니다. [현재 코드 설명](../docs/current/01-code-reading.md)을 참고하세요. 현재 구성을 위해 Nginx를 추가로 실행하지 않습니다.
