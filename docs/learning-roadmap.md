# 작은 단계별 학습 로드맵

한 단계는 하나의 질문과 확인 가능한 결과를 갖습니다.
각 단계가 항상 커밋 하나와 일치하는 것은 아닙니다. 코드와 그 동작을 검증하는 테스트는 함께 커밋합니다.

## 진행 규칙

- 작업 전에 왜 필요한지, 무엇이 바뀌는지 설명합니다.
- 작은 단위를 구현한 뒤 확인 결과와 핵심 개념을 설명합니다.
- 중요한 설계 선택에는 이유와 대안을 기록합니다.
- 이해를 확인할 질문은 제시하되, 매 작업마다 승인을 요구하지 않습니다.
- 한 번에 전체 기능을 생성하지 않고 학습 가능한 단위로 진행합니다.
